# Intel RealSense D435i RGB-D trong `nav_ws`

Đây là profile **mô phỏng tương thích D435i** cho Gazebo Harmonic và ROS 2
Jazzy. Nó không thay thế driver `realsense2_camera` khi cắm camera vật lý.

## Profile đang dùng

| Thuộc tính | Giá trị |
|---|---|
| RGB và depth đã align | `848 x 480` |
| Frame rate | `30 Hz` |
| Depth FOV ngang | `87°` |
| Dải depth mô phỏng | `0.195–10.0 m` |
| Depth encoding | `32FC1`, đơn vị mét |
| Point cloud | `sensor_msgs/msg/PointCloud2` |
| Camera IMU | `sensor_msgs/msg/Imu`, 200 Hz |

D435i thật hỗ trợ depth `848x480` tới 90 FPS. Mô phỏng mặc định dùng 30 FPS
để giữ Gazebo ổn định; tăng `<update_rate>` lên `60` hoặc `90` sẽ tốn GPU/CPU
hơn. RGB và depth mô phỏng dùng cùng optical frame để dữ liệu đã được align.

## Topic

| Topic | Message | Ý nghĩa |
|---|---|---|
| `/camera/color/image_raw` | `sensor_msgs/msg/Image` | Ảnh RGB `rgb8` |
| `/camera/depth/image_rect_raw` | `sensor_msgs/msg/Image` | Depth `32FC1`, mét |
| `/camera/color/camera_info` | `sensor_msgs/msg/CameraInfo` | Intrinsic ảnh màu |
| `/camera/depth/camera_info` | `sensor_msgs/msg/CameraInfo` | Intrinsic depth |
| `/camera/depth/color/points` | `sensor_msgs/msg/PointCloud2` | Point cloud RGB-D |
| `/camera/imu` | `sensor_msgs/msg/Imu` | IMU mô phỏng D435i |
| `/camera/obstacle/range` | `sensor_msgs/msg/Range` | Khoảng cách từ camera |
| `/camera/obstacle/distance` | `std_msgs/msg/Float32` | Khoảng cách từ tâm robot |

Hai topic `obstacle` do UI ở Terminal 3 tạo ra. Khoảng cách được lấy từ các
pixel depth hợp lệ của thành phần gần nhất trong vùng nhìn thẳng phía trước.
Vùng này được giới hạn tới 3 m để loại phần lớn tường hai bên hành lang. Đây là
phát hiện vật cản bằng hình học depth, không phải mô hình AI phân loại người.
Giá trị `inf` có nghĩa là chưa có vật cản trong cửa sổ đo `0.195–3.0 m`.

## Build một lần sau khi thay đổi

```bash
cd ~/nav_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select custom_corridor
source install/setup.bash
```

## Terminal 1 — Gazebo và camera

```bash
cd ~/nav_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=42

ros2 launch custom_corridor corridor_tb3.launch.py \
  width:=0.90 obstacle:=human gui:=true rviz:=false
```

Không chạy hai phiên Gazebo cùng `ROS_DOMAIN_ID=42`. Hai publisher `/clock`
hoặc việc khởi động lại simulator trong khi node cũ còn sống sẽ làm thời gian
ROS lùi và gây cảnh báo `Moved backwards in time`.

## Terminal 2 — kiểm tra dữ liệu

```bash
cd ~/nav_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=42

ros2 topic list | grep camera
ros2 topic hz /camera/depth/image_rect_raw
```

Kiểm tra một frame depth:

```bash
ros2 topic echo /camera/depth/image_rect_raw --once \
  --field encoding
```

Kết quả phải là `32FC1`. Có thể xem ảnh màu thuần bằng:

```bash
QT_QPA_PLATFORM=xcb ros2 run rqt_image_view rqt_image_view \
  /camera/color/image_raw
```

Lệnh rqt chỉ xem ảnh; không có overlay khoảng cách và không điều khiển robot.

## Terminal 3 — UI khoảng cách và điều khiển robot

```bash
cd ~/nav_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=42

QT_QPA_PLATFORM=xcb ros2 run custom_corridor d435i_viewer.py
```

Click vào cửa sổ UI trước khi bấm phím:

| Phím | Tác dụng |
|---|---|
| `W` | Đi thẳng |
| `S` | Đi lùi |
| `A` | Quay trái |
| `D` | Quay phải |
| `X` hoặc `Space` | Dừng |
| `Q` hoặc `Esc` | Dừng và thoát |

UI hiển thị ảnh RGB, depth heatmap, bounding box vùng gần nhất, khoảng cách từ
camera và khoảng cách đã bù `0.08 m` từ tâm robot. Lệnh chuyển động tự hết hạn
sau `0.35 s`; giữ hoặc bấm lặp phím để robot tiếp tục chạy. Đây là cơ chế an
toàn để robot tự dừng nếu cửa sổ mất focus.

Trong lúc UI đang chạy, xem khoảng cách bằng topic ở terminal khác:

```bash
ros2 topic echo /camera/obstacle/range
ros2 topic echo /camera/obstacle/distance
```

Không đồng thời gửi Nav2 goal và điều khiển `W/A/S/D`, vì cả hai cùng publish
`/cmd_vel`. Dừng Nav2 goal trước khi teleop thủ công.

Có thể chỉnh tốc độ khi chạy UI:

```bash
QT_QPA_PLATFORM=xcb ros2 run custom_corridor d435i_viewer.py --ros-args \
  -p linear_speed:=0.10 \
  -p angular_speed:=0.60 \
  -p detection_max_range:=3.0
```

## Cảnh báo `Moved backwards in time`

`robot_state_publisher` hiện đặt `ignore_timestamp:=true` để không tạo warning
storm sau khi clock reset. Tuy nhiên vẫn cần đóng sạch phiên cũ bằng `Ctrl+C`,
đợi các process kết thúc rồi mới launch lại. Nếu warning vẫn xuất hiện, kiểm tra:

```bash
ros2 topic info /clock -v
ps aux | grep -E 'gz sim|parameter_bridge' | grep -v grep
```

Chỉ nên có một Gazebo publisher `/clock` trong domain đang dùng.
